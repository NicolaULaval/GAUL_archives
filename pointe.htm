L'ogive de Sears-Haack
Description

L'ogive de Sears-Haack fabriquée en fibre de verre. Elle est l'une des plus performantes pour les vitesses subsoniques (Ma < 1.0).

Caractéristiques de l'ogive de Sears-Haack
  • Longueur : 457 mm (18 in)
  • L'aire de profil : 2134 mm2 (84 in2)
  • L'aire mouillé : 6705 mm2 (264 in2)
